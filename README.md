# Power BI HR Dashboard Template

A Power BI HR dashboard template built with dummy HR data.

This project is meant to provide a practical example of how HR data can be turned into an interactive Power BI report. The dashboard is mainly designed as inspiration for Dutch and European SMEs, but the structure can be adapted to other organizations as well.

## Overview

The dashboard includes HR-focused visuals and report pages such as:

* Employee overview
* Headcount analysis
* Department breakdown
* Age distribution
* Salary insights
* Attrition-style analysis
* HR management reporting views

The report is built with dummy data and is intended for learning, inspiration, and template purposes.

## Files included

This repository includes:


Depending on the version, the PBIX file may contain cached demo data.

## How to use the dashboard

1. Download or clone this repository.
2. Open the `.pbix` file in Power BI Desktop.
3. Explore the dashboard using the cached demo data.
4. If you want to refresh the report, reconnect the data source to your own Excel file or dataset.

## Important note about data refresh

The PBIX file may include cached demo data, so the report can be opened and explored directly.

However, refresh may not work out of the box because the original Excel source path was local to my machine. To refresh the report, you may need to update the data source path in Power BI.

In Power BI Desktop:

1. Go to **Transform data**
2. Open **Data source settings**
3. Change the source to your own Excel file or dataset
4. Apply changes and refresh the report

## Dummy data

This dashboard uses dummy HR data. No real employee data is included.

Before reusing this dashboard with your own data, make sure your data is properly anonymized and that you follow all relevant privacy and data protection requirements.
